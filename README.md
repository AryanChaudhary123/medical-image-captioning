# 🧠 Medical Image Captioning using Generative Transformers

An AI-powered full-stack application that classifies brain tumors from MRI images and generates medical captions using Vision Transformers (ViT), Knowledge-Aware Networks (KAN), and Generative Transformers. It also integrates Grad-CAM for visual explanations and a user-friendly React interface for real-time predictions.
